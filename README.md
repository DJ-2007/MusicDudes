# Music With Dudes

A Spotify-inspired real-time music sharing web application built with React, Node.js, Express, Socket.IO, and ytdl-core.

## Structure

- `backend/` - Express + Socket.IO server and YouTube audio streaming endpoint
- `frontend/` - React + Vite UI with Spotify-style layout

## Run locally

1. Install backend dependencies:
   ```bash
   cd backend
   npm install
   ```
2. Install frontend dependencies:
   ```bash
   cd frontend
   npm install
   ```
3. Start the backend:
   ```bash
   npm run dev
   ```
4. Start the frontend:
   ```bash
   npm run dev
   ```

## Environment

- Backend: `backend/.env`
- Default backend URL: `http://localhost:4000`
- Default frontend URL: `http://localhost:5173`
